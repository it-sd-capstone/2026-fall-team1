# Player Input Test

## Test Steps
1. Run the SampleScene through the editor
2. Press the spacebar or "A" on a controller
3. Press W on the keyboard or move the left stick up on a controller

## Expected Results
* Step 2 should result in the player character jumping
* Step 3 should display a movement vector value of (0.00, 0.00, 1.00)
