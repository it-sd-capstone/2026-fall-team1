Description
Relics of Draemoor is a 3D, third-person medieval action-platforming game that has a main hub world, with three individual dungeons. To progress the game the player will have to explore, solve puzzles, and fight enemies, including a theme boss. The player can unlock new abilities that will help access previously inaccessible areas. The dungeons will have their own themes (ice/water, fire, and crypt) that will end with a boss fight requiring the use of the dungeon's weapon.

Installation
1) Download or clone the repository from GitHub
git clone git@github.com:it-sd-capstone/2026-fall-team1.git
2) Install Unity Hub
3) Install Visual Studio or another C# IDE
4) In Unity Hub, install Unity Version 6000.6.8f1
5) Open Unity Hub and select Projects
6) Select Add -> Add project from disk
7) Browse and select the 2026-fall-team1 folder inside of the cloned repository
8) Open the project in Unity

Testing
To test the game
1) Open the project in Unity.
2) Open the main menu scene and press the play button in Unity Editor.
3) When the menu scene loads click Start Game to open the Sample Scene.
4) Test the player's movement, jumping, and camera controls.
5) Test interactions with objects within the scene.
6) Stop the game using the Stop button in the Unity Editor when finished.
