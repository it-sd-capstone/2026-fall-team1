Installation
1) Download or clone the repository from GitHub
git clone git@github.com:it-sd-capstone/2026-fall-team1.git
2) Install Unity Hub
4) In Unity Hub, install Unity Version 6000.6.8f1
5) Open Unity Hub and select Projects
6) Select Add -> Add project from disk
7) Browse and select the 2026-fall-team1 folder inside of the cloned repository
8) Open the project in Unity
